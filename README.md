# LLM for Medical

Learning AI for medicine — from the foundations up, heading toward **LLMs in medicine**. Built by a final-year MBBS student who can already code.

## Direction

Not MBBS exam prep. This repo is for learning how AI — especially large language models — works in medicine: how to build with it, evaluate it, and use it safely.

## The plan

An 8-week roadmap, ~1–2 hours a day, revision first (the PGET + FCPS Part I plan always comes before this):

| Phase | What | When |
|---|---|---|
| [Phase 0 — Setup](steps/phase-0-setup.md) | Python refresh, Colab GPU, this repo | Days 1–3 |
| [Phase 1 — ML Foundations](steps/phase-1-ml-foundations.md) | How learning works, classic algorithms, unsupervised + the maths that matters | Weeks 1–3 |
| [Phase 2 — Deep Learning & Medical Data](steps/phase-2-deep-learning.md) | Neural networks, CNNs, medical datasets | Weeks 4–5 |
| [Phase 3 — The Small Project](steps/phase-3-project.md) | ECG rhythm classifier (or the RAG chatbot alternative) | Weeks 5–8 |
| [Phase 4 — Beyond the Project](steps/phase-4-beyond.md) | LLMs in medicine, papers, evaluation & safety | Ongoing |

## Weekly rhythm

- **Mon–Fri:** 45–60 min theory + 30 min code exercise.
- **Saturday:** project work only — no new theory.
- **Sunday:** 30-min checkpoint — what did I learn, what broke, what's next. Write 5 lines here.

If a week slips, don't restart — just continue from where you stopped. Consistency beats intensity.
